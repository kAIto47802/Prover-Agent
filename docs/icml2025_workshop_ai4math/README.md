# Materials Related to ICML 2025 Workshop on AI for Math (Earlier Version)

This directory contains materials related to the **earlier workshop version** of our paper,
presented at the *2nd AI for Math Workshop at the 42nd International Conference on Machine Learning*.

The work was later discussed in an invited talk shortly after the workshop, based on the same version.
The slides used in that talk are also included here:

- [Poster (PDF)](poster.pdf)—presented at the ICML 2025 Workshop on AI for Math  
- [Slides (PDF)](slides.pdf)—used in a subsequent invited talk

For the most latest version of the work, please refer to [our latest paper](https://arxiv.org/abs/2506.19923) and updated results.
